# About mio

我是 mio（みお），一名专注于 Web 安全与 GPU 计算的学生，正在以长期规划的方式构建自己的技术体系。  
这个博客用于记录我的学习轨迹、实验过程、研究方向，以及一些值得被整理下来的思考。

## 技术方向 · Focus

**Web 安全 / Ethical Hacking**  
目前主要学习和实践以下领域：  
- Web 漏洞分析：XSS、SQLi、RCE、反序列化、权限维持等  
- PHP / MySQL 安全相关环境的理解与搭建  
- CTF 题目分析，包括流量取证、逆向基础、Web 解题  
- WAF 绕过原理探索与测试  
- 实战安全思维的培养：从问题推演攻击链、从错误定位根因

**GPU 计算 / CUDA**  
- 基于 NVIDIA RTX 5070 的本地 CUDA 实验环境  
- CUDA 基础、内存模型、调优思路  
- 使用 Nsight 等工具进行性能分析  
- 为未来更大规模的并行计算与安全方向做储备

我期望未来能同时在 *Web 安全* 与 *GPU 并行计算* 交汇的领域里找到属于自己的位置。

## 写作风格 · How I Document

我会尽可能做到：  
- **准确与可复现**：给出明确的环境、参数、复现方式  
- **逻辑清晰**：从现象→推理→验证→结论  
- **温和但严谨**：保持怀疑态度，不急于下结论  
- **带一点温度**：技术是工具，但写字时仍然希望保持人性化
